# HRRR GNN-CSGD CONUS Weather Hub

Development website for HRRR-based GNN-CSGD precipitation guidance.

Planned products:
- Separate 6-, 12-, and 24-hour precipitation forecasts.
- Initialization-date and forecast-window selection.
- Expected precipitation and threshold-exceedance probabilities.
- Model comparison: Raw HRRR, ANN-CSGD, and GNN-CSGD.
- Verification and downloadable forecast products.

Status: starter interface only. No forecast data are published yet.

Keep credentials, training arrays, and model checkpoints outside this repository.
