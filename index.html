Data and interpretation

All four systems use the same HRRR initialization, valid window, CONUS 0.25° land grid and finite MRMS observations. MRMS 24-hour totals require four consecutive 6-hour Pass2 fields; missing components remain pending.

CRPS includes the zero-censoring correction. Raw HRRR CRPS equals MAE. MAE, RMSE and bias for neural models use their distribution means. Positive thresholds define events as observations ≥ the stored float32 threshold. Raw HRRR threshold forecasts are binary 0/1 indicators.

BSS versus raw HRRR and BSS versus monthly MRMS climatology are separate selections. The monthly reference uses 2020–2025 observations; unavailable threshold climatology is shown as unavailable. Reliability uses ten probability bins. Counts represent grid-cell/window cases, not independent storms. These are point estimates without confidence intervals.

The CNN checkpoint was selected on 2024 validation data. Its validation CRPS is 1.049463 mm; that number is not the score for the initialization selected here. CNN 6-hour and 12-hour models are not included.

Technical details

How GNN-CSGD works

Three separately trained models produce 6-, 12-, and 24-hour precipitation guidance using the same CONUS land grid.

1. Forecast inputsTwelve input features describe each land grid cell for the selected accumulation duration.
2. Spatial learningGraphSAGE combines information from neighboring land grid cells to learn precipitation patterns.
3. Precipitation distributionA censored, shifted gamma distribution represents the chance of zero rainfall and the range of positive rainfall amounts.
4. Maps and probabilitiesThe predicted distributions provide expected rainfall and probabilities of exceeding selected precipitation thresholds.

Forecast grid: 0.25° CONUS · 13,318 land grid cells · Forecast horizon: 48 hours.
