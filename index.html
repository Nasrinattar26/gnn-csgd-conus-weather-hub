How GNN-CSGD works

A shared spatial graph supports three separately trained duration models.

1. HRRR predictors12 duration-specific features per land node.
2. GraphSAGELearned aggregation across the 8-neighbor land graph.
3. CSGD parametersShape, scale, and nonpositive shift define a marginal distribution at each node.
4. Forecast productsExpected precipitation and exceedance probabilities from each distribution.

Current graph: 13,318 land nodes. A finer display image is not a higher-resolution model. Spatial message passing does not by itself produce a joint space-time ensemble.
