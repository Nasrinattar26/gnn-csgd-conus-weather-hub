ForecastsVerification metrics

Understand the evidence

Forecast verification, explained.

A practical companion to NOAA’s Forecast Verification Glossary, adapted to matched HRRR, ANN-CSGD, GNN-CSGD and CNN-CSGD rainfall forecasts.

Five questions to ask

Amount: How far are rainfall totals from observations?

Events: Which threshold exceedances were detected or missed?

Probabilities: How accurate and calibrated were the stated chances?

Discrimination: Were higher probabilities assigned to events?

Skill: Was the forecast better than a clearly named reference?

Read every score with its sample

Match the model versions, initialization, accumulation window, rainfall threshold and observed grid cells. Counts describe grid-cell/window cases, not independent storms.

Rainfall diagnostics default to inches; MSE, covariance and variance use squared inches. Probabilities and skill scores are dimensionless.

Zero denominators, missing MRMS and unavailable retained inputs stay explicitly unavailable. No score is replaced with a zero to fill a gap.

The four event counts

Event observedNo event observed
Event forecastH: hitF: false alarm
No event forecastM: missC: correct rejection

For example, “at least 1 inch” defines the observed event. Separately choose whether the forecast event means probability ≥ 50% or expected rainfall ≥ 1 inch. Those decisions produce different contingency tables.

Conventions that matter

Brier score: the existing binary score ranges from 0 to 1. The glossary’s category-vector score ranges from 0 to 2; for a binary event it equals twice the existing score. Both labels are explicit.

RPS: each ordered rainfall boundary contributes one squared cumulative-probability error. Raw RPS sums these errors; normalized RPS averages them. Thresholds must share an intersected sample mask. It is a discrete-category score, not CRPS.

Reliability and resolution: unnormalized components are shown alongside the existing normalized diagnostics. Ten-bin components need not sum back to the exact unbinned Brier score. The extension reports that residual.

References: sample climatology is computed from the selected verification cases. Historical monthly MRMS climatology is a separate baseline. Neither should be relabeled as the other.

Moment definitions: variance and covariance here divide by N. This makes the prediction-efficiency denominator the MSE of the constant sample mean. The N−1 sample estimator is a different convention.

Scope: new diagnostics use dated operational comparisons. The archived 2025 benchmark’s withheld CRPS values remain withheld; this update does not evaluate or retrain models.

Glossary terms and measures

Aliases are grouped together. General concepts remain explanations rather than invented numerical scores.

Accuracy

How close individual forecasts are to their matched observations. MSE, RMSE and MAE measure different aspects of amount error. Lower error is better.

Association / linear-correlation coefficient

Correlation measures linear co-variation. A model can have high correlation and still have a large bias. Undefined when either variable has zero variance.

r = Cov(f,y) / (SD(f) SD(y))
Base rate

Observed event frequency in the selected matched sample. It describes event rarity and is not, by itself, forecast skill.

ō = (H + M) / N
Bias / mean error

Average forecast amount minus observed amount. Positive values indicate overprediction; negative values indicate underprediction. Errors of opposite sign can cancel.

ME = mean(f − y)
Frequency bias

Ratio of forecast events to observed events. Ideal value 1; values above 1 indicate too many event forecasts. This differs from mean amount bias.

(H + F) / (H + M)
Bivariate histogram

A count matrix of forecast amount bins against observed amount bins. The viewer renders it as a heat map; its full counts are downloadable.

Box plot

A compact distribution view. Here the box spans Q25–Q75, the line is the median, and whiskers are Q10–Q90. These are spatial forecast-mean and observation distributions, not predictive intervals.

Brier score / probability score

Mean squared probability error for an event. The existing site uses the binary 0–1 convention. The glossary uses a category-vector convention; with two complementary categories its value is exactly twice the binary score. Lower is better.

BS = mean((p − o)²); two-category vector BS = 2 BS
Calibration / reliability (in-the-small)

Agreement between issued probabilities and observed frequencies. Forecasts near 30% should be followed by the event about 30% of the time across comparable cases. The unnormalized reliability component is lower for better calibration.

REL = Σ (nᵦ/N) (p̄ᵦ − ōᵦ)²
Categorical forecast

A yes/no or class forecast. The added viewer distinguishes probability ≥ a specified cutoff from expected rainfall ≥ a specified amount. Different rules answer different questions.

Conditional bias 1

Compare mean observed rainfall with the forecast in groups of similar forecast amounts. The conditional-observation plot and table show the means and quantiles; broad bins can hide structure.

Compare E[y | f] with f
Conditional bias 2

Compare mean forecast rainfall with observations in groups of similar observed amounts. This reverses the conditioning used in calibration.

Compare E[f | y] with y
Conditional distribution

The distribution of one variable within a specified value or range of another. The two directions of conditioning must not be interchanged.

P(y | f) or P(f | y)
Conditional quantile plot

Shows response quantiles within bins of a conditioning variable. The conditional-quantile selection plots Q10, median and Q90 for a chosen model. Tables and CSV retain bin counts and all three quantiles.

Contingency table

Four counts describe a binary forecast: hits, false alarms, misses and correct rejections. All categorical scores below are calculated from the same matched population.

N = H + F + M + C
Continuous forecast

An amount forecast, such as expected precipitation. For ANN/GNN/CNN amount verification, the point prediction is the predictive distribution mean.

Correct random forecast

The expected number of correct yes and no forecasts from independent random predictions with the same event marginals. This is the reference used by HSS.

E = [(H+F)(H+M) + (M+C)(F+C)] / N
Correct rejection

A no-event forecast accompanied by a no-event observation. Rare-event datasets often contain many correct rejections.

C
Covariance

Joint variation of forecast and observed amounts around their respective means. Its size depends on the measurement units. This implementation uses population moments, dividing by N.

Cov(f,y) = mean((f − f̄)(y − ȳ))
Critical success index / threat score

Fraction of cases involving a forecast or observed event that are hits. Correct rejections are excluded. Higher is better; event rarity affects the score.

CSI = TS = H / (H + F + M)
Cumulative forecast

Probabilities accumulated across ordered outcome categories. For rainfall, exceedance probabilities are converted to cumulative probabilities at ordered thresholds.

Fⱼ = P(Y < thresholdⱼ), with the operational boundary convention
Cumulative observation

The observed category encoded cumulatively at the same ordered boundaries as the forecast.

Oⱼ = 1 if y < thresholdⱼ, otherwise 0
Diagnostic verification

Examining multiple scores, sample counts and plots to understand particular strengths and weaknesses. A single winning score cannot describe all forecast qualities.

Discrimination / likelihood

How differently the model assigns probabilities when an event occurs versus when it does not. This differs from calibration.

Compare P(p | o=1) and P(p | o=0)
Discrimination diagram

Histograms of forecast probability conditional on observed events and non-events. The added chart uses solid and dashed lines, respectively. A class with no cases is undefined.

False alarm

A predicted event that is not observed.

F
False alarm ratio

Fraction of event forecasts that are wrong. Lower is better. Its denominator is forecast events, unlike the false-positive rate used for ROC.

FAR = F / (H + F)
Forecast verification

Comparison of forecasts with matching observations using the same initialization, valid accumulation period, spatial grid and event definition.

Gilbert skill score / equitable threat score

CSI adjusted for expected chance hits. Higher is better; zero is the random-reference level when defined.

ETS = (H − Hᵣ) / (H + F + M − Hᵣ)
Heidke skill score

Correct classifications relative to the number expected by chance under the observed and forecast event marginals. Higher is better. Degenerate zero-denominator cases are undefined.

HSS = (H + C − E) / (N − E)
Histogram

Counts or relative frequencies within specified bins. Forecast and observation amount histograms describe marginal distributions; probability-bin usage describes sharpness.

Hit

An event forecast accompanied by an event observation.

H
Hit due to chance

Expected hits if forecast and observation event occurrence were independent while preserving their marginal rates.

Hᵣ = (H + F)(H + M) / N
Joint distribution

The paired forecast–observation distribution. It describes their relationship; individual marginal distributions alone cannot recover that relationship.

P(f,y) = P(y|f)P(f) = P(f|y)P(y)
Marginal distribution

The forecast or observation distribution considered separately. The amount histograms, box summaries and probability usage provide these views.

P(f), P(y)
Mean

Arithmetic average. The viewer reports forecast and observation means on the same matched cells.

x̄ = Σx / N
Mean square error

Average squared amount error. Large errors receive more weight than small ones. It has squared rainfall units; lower is better.

MSE = mean((f − y)²)
Median

The 50th percentile. It is less sensitive to extreme values than the mean.

Q50
Miss

An observed event that was not forecast.

M
Nominal predictand

An outcome described by mutually exclusive classes whose ordering need not carry a numerical meaning. Multicategory Brier scores can assess category probabilities.

Normal distribution

A symmetric bell-shaped probability distribution defined by its mean and variance. It is a glossary concept, not a verification score. Rainfall and censored gamma forecasts are not assumed to be normally distributed here.

Ordinal predictand

An outcome described by ordered classes, such as rainfall amount categories. RPS respects their ordering.

Percent correct

Percentage of all forecasts classified correctly. It can look excellent when almost all cases are dry, so examine event-focused scores alongside it.

PC = 100(H + C) / N
Predictand

The variable or event being forecast. Here it is rainfall accumulation or threshold exceedance for a specified duration and valid window.

Prediction efficiency

Amount-error skill relative to predicting the mean observation of the selected sample. This descriptive sample reference differs from an independently estimated historical climatology.

1 − MSE / mean((y − ȳ)²)
Probability forecast

A forecast assigning probabilities to possible outcomes. Probabilities lie between 0 and 1; a complete set of exclusive category probabilities sums to 1.

Probability of detection

Fraction of observed events that were forecast. Higher is better, but forecasting an event everywhere can yield high POD with many false alarms.

POD = H / (H + M)
Quantile

A value below which a specified fraction of a distribution falls. The viewer reports Q10, Q25, median, Q75 and Q90 for matched amount samples.

Quartile

A quantile dividing the distribution into quarters: Q25, Q50 and Q75. The interquartile range is Q75 minus Q25.

IQR = Q75 − Q25
Ranked probability score

Squared errors of cumulative probabilities summed across ordered category boundaries. Here rainfall categories use every published threshold on one intersected common mask. Raw RPS has range 0 to K−1 for K categories; normalized RPS divides by K−1. Lower is better.

RPS = mean(Σⱼ(Fⱼ − Oⱼ)²)
Refinement / sharpness

Variation in issued probabilities, assessed without the observed outcomes. Probability histograms and variance show this attribute. Concentrated probabilities are useful only when also well calibrated; sharpness alone is not skill.

Var(p) and probability-bin usage
Reliability diagram

Observed event frequency versus mean forecast probability within each bin. The diagonal represents perfect calibration; sample counts help assess how much evidence supports each point.

Resolution: Murphy and Sanders

Murphy resolution increases as conditional event frequencies separate from the overall rate. Sanders resolution is the average remaining within-bin event uncertainty; lower is better. Both are shown unnormalized here.

RES = Σwᵦ(ōᵦ − ō)²; RES′ = Σwᵦ ōᵦ(1 − ōᵦ)
Robust measure

A statistic resistant to extreme values or departures from distribution assumptions. Median and IQR are examples; robustness is a property rather than one specific score.

Root mean square error

Square root of MSE, restoring rainfall units. Lower is better.

RMSE = √MSE
Sample climatology

A reference estimated from the verification sample itself. Its mean amount or event frequency provides a descriptive baseline, distinct from the site’s historical monthly MRMS climatology.

Skill

Improvement over a named reference forecast. Always identify both the score and its reference. For error scores, positive skill is better than the reference; a zero reference error makes the ratio undefined.

Skill = 1 − score / reference score
Standard deviation

Square root of variance, in the original units. The added diagnostics use population moments across the matched cells.

SD(x) = √Var(x)
Statistical characteristic

A property of a joint, marginal or conditional distribution, or of the correspondence between forecasts and observations. This is a general concept.

Success ratio

Fraction of event forecasts that were observed. Higher is better. It is complementary to FAR.

SR = H / (H + F) = 1 − FAR
True skill statistic

Detection rate minus false-positive rate, also called the Hanssen–Kuipers or Peirce score. Higher is better; undefined without both observed event classes.

TSS = H/(H+M) − F/(F+C)
Uncertainty

Variation in observations. Binary event uncertainty is largest at an event rate of 0.5 and vanishes when all cases belong to one class.

UNC = ō(1 − ō)
Variance

Mean squared deviation from the mean. This implementation explicitly uses denominator N; the unbiased sample estimator would use N−1. Units are squared.

Var(x) = mean((x − x̄)²)
Verification measure

A numerical function describing an attribute of paired forecasts and observations. Some glossary entries describe concepts or diagrams rather than additional scalar scores.

Related measures already used on this website

False-positive rate

Fraction of observed non-events incorrectly forecast as events; this is the horizontal ROC coordinate.

POFD = F / (F + C)
CRPS / CRPSS

CRPS scores the complete predictive rainfall distribution. The existing dated comparisons include the zero-censoring correction. CRPSS uses raw HRRR as its reference.

CRPSS = 1 − CRPS / CRPS(raw HRRR)
ROC / AUC

ROC varies the decision cutoff and compares detection against false-positive rate. AUC measures probability ranking, not probability calibration. The site’s dated ROC is exact, with ties grouped.

Brier / ranked probability skill

The extension labels sample-climatology and historical monthly-climatology skill separately. RPS skill requires the same category boundaries and matched population for model and reference.

BSS = 1 − BS/BSref; RPSS = 1 − RPS/RPSref
Mean absolute error

Average absolute amount error, in rainfall units. Already present in the four-system viewer; the extension also exposes it for dated three-system data.

MAE = mean(|f − y|)
Expected calibration error

Weighted mean absolute difference between bin-average probabilities and observed frequencies. Existing plots use ten probability bins.

ECE = Σwᵦ |p̄ᵦ − ōᵦ|

Data availability

Contingency scores at 10–90% probability cutoffs, base rate, binary Brier diagnostics, binned discrimination and reliability are available from published counts and probability bins. MSE is obtained by squaring RMSE. RPS can be recovered by summing threshold Brier scores only when their sample counts and mask hashes match.

Correlation, amount covariance, distribution quantiles, joint amount histograms, conditional amount diagnostics, amount-based categorical scores and multicategory Brier scores require retained paired inputs. The extension verifies those inputs against the published scores before adding results. It never invents missing values or reconstructs exact probabilities from bin midpoints.
